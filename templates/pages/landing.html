Core Specifications

Engineered for Strict Document Sovereignty

Controlled document sharing without giving recipients permanent or full-vault access.

Encrypted Document Vault

Categorize sensitive medical records, vehicle registrations, and identity documents in an isolated, secure account vault.

Granular Share Passes

Hand-pick individual documents for each situation (e.g. only lab tests for a clinic) without exposing unrelated files.

QR + Key Dual Authorization

QR codes only point to protected endpoints. Recipients must supply the separate temporary Share Key before any file is unlocked.

Server-Enforced Expiration

Passes automatically expire after your selected window (10m, 30m, 24h). The backend denies expired requests immediately.

View vs. Download Controls

Enforce whether recipients can only preview documents on-screen or download raw files to their device.

Real-Time Access Logs

Monitor when your share passes were validated, accessed, or revoked with complete server-side timestamped event records.

Workflow

How Passli Operates

A streamlined, secure three-stage protocol.

STAGE // 01

Upload & Categorize

Store medical records, identity documents, and certificates in your encrypted personal vault.

STAGE // 02

Issue Temporary Pass

Select specific documents, configure permissions, set the expiration timer, and generate a QR endpoint + Share Key.

STAGE // 03

Keyed Recipient Access

The recipient scans the QR code and supplies the Share Key to access only the permitted files before expiration.
