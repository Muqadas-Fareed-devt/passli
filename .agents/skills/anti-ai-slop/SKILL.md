# Anti-AI Slop Engineering & Design System

This skill enforces high-craft standards to prevent generic "AI slop" across UI design, copywriting, and code architecture.

## 1. Visual Design: High-Craft Restraint vs. Cliché AI Slop

### What to Avoid (AI Slop Traps):
- Generic purple/magenta gradient overdose with ungrounded floating nebulas.
- Cliché generic emoji walls and superficial decorative clutter.
- Excessive cartoonish rounded corners and blurry, unreadable glassmorphism.
- Gimmicky over-animations that distract from core functionality.
- Fake metrics ("99.9% AI synergy") and generic stock imagery.

### What to Build (High-Craft Standard):
- **Precision Color System**: High-contrast, grounded slate/zinc/dark surfaces (`#090d16`, `#0b0f17`, `#111827`) with functional, intentional accents (e.g. Cobalt Blue `#2563eb`, Emerald `#10b981`, Crisp Silver `#e2e8f0`).
- **Typography Craft**: Intentional font pairing, calibrated line-heights, letter-spacing tracking (`-0.02em` on titles, `+0.05em` on micro-labels), and clear contrast hierarchy.
- **Hairline Geometry & Depth**: Crisp 1px borders with subtle alpha shifts, restrained drop shadows, and structured grid rhythm inspired by Linear, Stripe, and Apple.
- **Authentic Components**: Real-world functional previews (real document badges, exact file types, cryptographic hash previews, keyboard shortcuts).

## 2. Product Copywriting: Crisp Human Clarity

- **No Corporate / AI Buzzwords**: Replace "Revolutionize your document ecosystem with next-gen seamless paradigm" with "Store personal files in your vault. Share specific documents with a QR pass and temporary access key."
- **Direct & Action-Oriented**: Clear labels, unambiguous error messages, and transparent security disclosures.

## 3. Code & Architecture Quality

- Zero dead code, zero unneeded dependencies, zero empty placeholders.
- Strict defensive programming, OWASP security enforcement, and high-performance server responses.
