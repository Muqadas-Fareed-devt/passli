# Anti-AI Slop & No-Slop UI Engineering Standard

Based on `no-slop-ui` (LeoStehlik) and `unslop-ui v2` principles, this skill ensures clean, human-crafted interfaces.

## 1. Eliminate AI Slop Tells

- **No Repetitive Eyebrow Tags**: Remove decorative pills, tags, and badges before every heading (e.g. `[DEFENSIVE CAPABILITIES]`, `[ARCHITECTURAL ASSESSMENT]`). Let clean typography speak for itself.
- **No Neon Radial Overdose**: Avoid glowing gradient halos and oversaturated purple/magenta cyberpunk tropes.
- **No Artificial Clip-Art Infographics**: Never embed cartoonish, AI-generated diagrams with giant bubble text. Use authentic photography or native CSS/SVG components.
- **No Robotic Copywriting**: Avoid generic buzzwords ("seamless synergy", "next-gen paradigm") and fragmented em-dash sentences. Write clear, direct, human English.

## 2. Human-Crafted Layout & Precision

- **Asymmetric Visual Rhythm**: Content-first split layouts, real product UI elements, and natural spacing.
- **Authentic Assets**: Use verified, high-resolution photography from curated sources (e.g. Unsplash) seamlessly integrated with 1px hairline borders.
- **Functional Navigation**: Ensure all navbar links point to valid, functional DOM sections (`#features`, `#how-it-works`, `#security`).
- **Defensive Engineering**: Clean, tested, modular Django code with strict input validation and zero boilerplate.
