# Anti-AI Slop Rule

1. **Design Quality**: Never generate generic AI-slop interfaces (e.g. oversaturated purple blobs, random floating nebulas, ungrounded emojis, fake buzzwords).
2. **Precision & Craft**: Build interfaces with Stripe/Linear-grade precision: crisp typography, structured dark/light geometry, hairline dividers, authentic functional widgets, and fast micro-interactions.
3. **Copywriting**: Write clear, direct, human-crafted product copy. Never use hollow buzzwords ("seamless synergy", "next-gen AI revolution").
4. **Engineering Rigor**: Write production-grade, maintainable code with strict input validation and zero boilerplate bloat.
